# 任务锚控制

## 定位与边界

操作 session 级短期状态 `.runtime/focus/anchor.json`。没有自动 Hook 捕获、更新或提醒；本 Skill 是任务锚唯一入口，只在用户显式调用时查看、设置、清除和执行漂移自检。

## 输入

| 输入 | 动作 |
|------|------|
| 无参数 | 查看已保存任务锚；不存在时依据近期对话给出当前主线，并立即自检 |
| `<文本>` | 将任务锚更新为该文本 |
| `clear` | 删除手动任务锚文件 |

## 核心流程

1. 读取 `.runtime/focus/anchor.json`。文件不存在且无参数时，依据近期对话说明“没有保存手动锚；当前主线判断为：<任务>”，完成一次自检后停止，禁止静默创建文件。
2. 按输入执行：
   - 无参数：显示 `anchor`；对照近期工作判断是否仍属该任务。旧文件存在 `session` 或 `turns` 时只忽略兼容字段，不依赖也不更新它们。
   - 带文本：将文件规范化为只含 `anchor` 的 JSON，用 UTF-8 和 `ensure_ascii=False` 写回。
   - `clear`：删除整个 `anchor.json`，不得只清空字段。
3. 无参数自检时只给一个结论：
   - `✓ 仍在原任务`
   - `⚠ 疑似漂移 → <前置阻塞 / 附加扩张 / 无关支线> → <spinoff / 内联 / todo / 新任务>`

## 输出与验证

- 更新后回复：`✓ 锚已更新为：<文本>`，并重新读取文件确认字段。
- 清除后回复：`✓ 手动锚已清`，并确认文件已不存在。

## 停止条件

- JSON 无法解析或缺少预期字段：停止写入并报告损坏内容的位置。
- 漂移类型无法确定：标记“未验证”，不要强行改锚。

## 禁止事项

- 禁止把任务锚当长期 memory；长期知识使用 `summary`。
- 禁止宣称后续消息会自动捕获、更新或提醒任务锚。
- 禁止把与“当前主任务是什么”无关的内容写入任务锚。
