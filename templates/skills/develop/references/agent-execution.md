# develop Agent 执行与审计路由

> 仅在 D2/D3 已判断需要且允许 Agent 时读取，不因规模标签默认读取或委派。触发条件、验证与预算由 SKILL.md 及 confirm 管理，本文件只路由角色与交接。

| 已确定的需要 | 执行方式 |
|---|---|
| 独立事实缺口，已有调查不足 | light-explorer 只读定位，传入已有证据，避免重复搜索 |
| 独立实现子任务 | implementation-worker，给定唯一文件边界及接口 |
| 多个文件不重叠、无依赖的任务，确有并行收益 | [collab](../../collab/SKILL.md)，复用原任务记录及其整合/审计结果 |
| 适用独立审查 | review-auditor 独立读取需求、真实文件及 diff，不以实现者总结替代 |
| 有依赖或并行收益不足 | 主对话顺序实施，不硬凑并行组 |

委派携带目标、范围、已有授权/预算、证据、验收及必要验证；明确不可改的文件和已有改动，子 Agent 不替用户扩大范围。预算包括调研、实施、整合和审计，不因交接重置。
主对话消费真实结果，不重做仍有效的检查；新增检查须有具体风险依据。审查无发现时说明未验证范围，必需能力不可用时如实记录。失败计数与恢复点跨 Agent 继承。
