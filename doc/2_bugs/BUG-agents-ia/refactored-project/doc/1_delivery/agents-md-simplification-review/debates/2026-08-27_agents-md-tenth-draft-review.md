## 议题

1. 是否足够精简，且每类决定只有一个规范 owner。
2. 是否对人类友好，能从具体事情找到位置与入口。
3. 是否无语义损失，包括主体、强度、触发、顺序、例外和跨平台入口。
4. 自动验证是否能阻断已知反例，而不是只验证正确样本。

## 第九版阻断及第十版修复

| 第九版阻断 | 第十版处理 |
|---|---|
| `~~~`、缩进代码和未闭合结构可绕过语义检查 | 统一可见 Markdown 扫描器，并加入正反例 |
| 项目标题可藏在 HTML 注释中骗过 Hook | Hook 只统计可见标题，未闭合注释 / fence fail closed |
