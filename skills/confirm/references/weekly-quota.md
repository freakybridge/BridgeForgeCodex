# 任务预算与周额度预估

> 每次新报或调整任务 token 预算时读取；同轮已核实的系数和配置可复用。
> 本文件是计算与显示规则的唯一事实源。周额度是经验预估，不是官方固定 token 配额或费用承诺。

## 1. 对外格式

只输出一行：`预计消耗约 N token，占周额度约 y%。`

- N 包含调研、主/子 Agent、实施、验证、合理返工与收尾余量；预算定义仍以 confirm 主入口为准。
- y 是整周总额度的百分比（消耗百分点），不是剩余额度百分比，不把当前已用比例加入 y。
- y 在所有组件求和后保留一位小数；正数不足 0.1% 显示 `低于 0.1%`，零 token 才显示 0%。
  例如：`预计消耗约 100 token，占周额度低于 0.1%。`
  预计超过 100% 不截断成 100%；额度是否足够另按原任务约定和平台限制处理。
- 系数、来源和假设保留在内部，用户追问时再展开。预算 y 不能作为实际扣减或实测结果。
- 一次确认整体预算；已授权范围内重排子任务或切换 Skill 不重新报批。预算或组件配置变化时重算
  并更新 N/y，即使 token 总量未增加；是否补充授权另按范围、风险和预算规则判断。

## 2. 选择系数

识别账户/套餐、quota bucket、实际模型、速度、任务类别和 token 口径。用户级默认配置不一定是
当前会话配置。可用时读取原生额度接口，按 windowDurationMins=10080 识别周窗口，不固定选择
primary/secondary。接口不可用时仍可用未失效的本机记录给初估。

用户明确固定的系数优先；否则按以下顺序选择，已有有效决定直接继承：

1. 相同账户/套餐/bucket、模型、速度、类别、口径的有效校准系数；输入/输出和缓存结构明显改变时，
   选择相应样本组或降为暂定估计，不把 Goal 计数等同于订阅计费模型。
2. 同配置、用户接受或有来源记录的临时系数。样本含其他会话干扰时可作暂定初估，不升级成准确
   归因或永久上限。不能为了校准专门发起付费任务；有临时依据时不默认回复“暂不可估算”。
3. 跨速度仅在官方明确给出同模型的“订阅额度”倍率时换算，记录出处和核验日期。API 价格、
   购买 credits 的倍率或模型定价比例不能直接当作周额度倍率。
4. 不同模型/类别无适用系数时，不静默套当前模型系数。先用用户已接受的该配置参考或可归属的
   历史样本；完全无依据时只补问一次关键系数/参考选择，不编造 y 或循环解释“无法精确”。

本机记录为项目 `.runtime/task-budget/weekly-quota.json`，不进入分发 manifest，不写 Memory 或
共享模板。用户提供的既有个人校准记录可只读复用，不跨项目写入。缺文件时先消费当前对话已有
决定，获准开发/记录后再落盘；只读咨询不能为补文件产生写入。

## 3. 计算与合并

组件 i 的 N_i 为预算 token，k_i 为每 10000 个同口径 token 消耗的周额度百分点：

```text
p_i = N_i / 10000 * k_i
N = sum(N_i)
y = sum(p_i)
```

- 主 Agent 与子 Agent按实际配置分项估算；已经包含子任务的整包预算不能再与子任务相加。
  同配置的未分配余量作为一个组件，混合配置的余量分配规则也应记录。
- token 口径匹配预算计数。若用 input_tokens - cached_input_tokens + output_tokens，不再加缓存
  或 reasoning_output_tokens；缓存的额度影响包含在同配置样本中，不能当作免费。
- 模型、速度或范围改变后重算受影响组件；已批准范围内的重分配不等于扩大授权。
- 图片、语音等独立类别使用自己的观察单位/样本，不能硬套文本 token 系数。只有具备已确认的
  token 预算和换算关系才合并到该格式；纯编译/等待时长不虚构为模型 token。

## 4. 后续校准

利用实际任务开始/结束的既有观察点读取额度与同口径累计 token，不新增轮询或守护进程。
只保存必要数值和配置，不保存对话正文、凭证或业务文件。

```text
k_sample = (used_percent_after - used_percent_before)
           / (tokens_after - tokens_before) * 10000
```

接纳有效样本必须满足：token 和百分点增量为正、同一周窗口无重置/套餐变更、配置不变，且该时段
无其他用量干扰或已覆盖同一账户全部相关消耗。账户总体变化不能自动归于一个聊天；多设备、云任务、
其他应用或并发会话无法覆盖时，保留暂定值，不自动覆盖校准值。
百分点有取整和延迟，零变化不等于免费。优先使用至少 2 个百分点的完整样本，小样本仅留作观察；
不同 resetAt 的观察不能拼成一个增量。新周重置不使同配置历史系数失效，但新任务重新取观察起点。

以同配置最近至少三个有效样本的 k_sample 中位数更新系数，保留样本数、时间与来源。
不足三个时保持 provisional；用户固定系数未经许可不覆盖。套餐或官方额度政策改变使旧系数失效。

## 5. 本机记录字段

schema_version=1、profiles 数组；每项保存 account_key（原生账户 ID 的 SHA-256 匿名标识）、plan、limit_id、model、speed、
category、token_basis、points_per_10k_tokens、status（provisional/calibrated/user_fixed）、source、
observed_at、samples。样本含 before/after 的 used_percent、tokens、reset_at、window_minutes，以及
attribution（isolated/account_complete/contaminated）。只有前两类在其他条件满足时可参与校准。
字段冲突、负数、非有限值或未知口径时保留原文件并报告，不把损坏数据当作零或无来源的新系数。

产品只分发规则和测试样例，不预置某个用户的经验数值。
